## 02.2. RCN: точная схема данных

```solidity
struct Rabbit {                       // packed: цель — 1 cold SSTORE
  uint16  slotId;                     // физический вольер/позиция
  uint16  chipHashRef;                // индекс в ChipRegistry
  uint16  rarityScore;                // 0..1000
  Rarity  rarityTier;                 // Common..Mythic (0..5)
  Genotype genotype;                  // см. 06, 24 байта
  uint64  birthTs;
  uint32  sex : 1;                    // 0 doe, 1 buck
  uint32  neutered : 1;
  uint32  littersLifetime : 3;        // максимум 4 — enforced
  uint32  breedingsThisYear : 3;      // максимум 2 для самок
  uint64  nextBreedEligibleTs;
  uint16  inbreedingBps;              // коэффициент Инбридинга × 10 000

  uint16  careScore;                  // 0..1000 (репутация заботы)

}
```

## 02.3. CareInvoice (не токен, а объект экономики — важен для понимания)

```solidity
struct Invoice {
  uint32  period;         // 202603
  uint64  baseClover;     // 1800 / 2600 / 3600 по tier
  uint64  servicesClover; // ветеринария, груминг, ремонт (по факту)
  uint64  discountBps;    // от streak/titles/партнёров
  uint64  dueTs;          // +7 дней grace
  PaidState state;        // OPEN, PAID, AUTO_PAID_ENDOWMENT, OVERDUE, ESCALATED
}
```

Почему это инвойс, а не подписка в фиате: ончейн-инвойс позволяет (а) автопогашение из энддаумента кролика, (б) третьих лиц, которые могут «закрыть» чужой инвойс (механика boarding/rescue), (в) публичную статистику, (г) скидки за серии, (д) доказуемость того, что деньги на содержание реально собраны, до того как они потрачены.

## 02.4. EnrichmentItem: durability как экономический сток

Предметы **ломаются** — это самый недооценённый стик в GameFi, а у нас он физически честный: картонный тоннель кролик съедает за 3–6 недель.

| Предмет | Цена, $CLOVER | Срок (дней) | Стадия деградации | Welfare-эффект |
|---|---|---|---|---|
| Сено-стойка «Hay Feeder Pro» | 120 | 60 | 4 | +2 |
| Картонный тоннель | 40 | 21 | 6 | +3 (dig/chew) |
| Ивовый шар | 60 | 35 | 5 | +3 |
| Полка- лесенка ( Platforms) | 220 | 180 | 2 | +5 (вертикаль обязательна) |
| Домик-укрытие (2 входа) | 300 | 365 | 1 | +8 (без укрытия welfare падает быстро) |
| «Библиотека» (тема вольера) | 450 | 120 | 2 | +6, +stream CTR |
| Когтеточка-плита | 90 | 90 | 3 | +2 |
| Закалённая ветка (яблоня) | 25 | 14 | 8 | +1 |
| Пазл-кормушка | 150 | 120 | 2 | +6 (cognitive) |
| «Камина» (тёплый настил) | 180 | 200 | 2 | +4 зимой |

Деградация: при каждом «обслуживающем» действии животного — вероятность списания 1 стадии. На 0 стадии предмет исчезает (burn) и welfare начинает падать: **пустой вольер — это минус 15 баллов за 3 недели.** Владелец может обновить предмет с 50% скидкой, если делает это в течение 14 дней после поломки («Repair window»).

## 02.5. GenotypeCard: «карта аллеля» как бесплатный онбординг

- Минтится бесплатно 1 раз в неделю любому адресу с ≥3 «Witness» (см. 08), либо покупается за 20 $CLOVER.
- Содержит 1 реальный аллель, извлечённый из опубликованного генотипа конкретного кролика (например «recessive: ruby-eye, от RCN #042, 2026-03-11»).
- Даёт: 1 бесплатный `MatchScan`/мес, +2 XP к любому breeding-действию, коллекционную серию (12 коллекций × 100 карт).
- Смысл: превращает «смотреть на кроликов» в «собирать генетику», не создавая pay-to-win.

## 02.6. LineageHouse («дом линии») — социальная надстройка

- Каждому «основателю-самцу» Genesis-когорты присваивается Дом (≤12). Все потомки по мужской или женской линии несут `houseId`.
- Владелец `LineageHouse` получает 5% от breeding-роялти всей линии (не путать с 40/40/20 по родителям — это надстройка сверху, финансируется из DAO-доли, а не из кармана игроков).
- Дома ведут «сезонные зачёты» (суммарный CareScore линии) → мотивация самоорганизовываться, а не только торговать.
- Это же — механизм «гильдий»: 3+ адреса могут создать `WarrenGuild` (soulbound-контракт) с общим пулом на содержание и ротацией прав.

## 02.7. Что намеренно НЕ является токеном

- Сами животные, их здоровье, ветеринарные записи (только хеши-доказательства и публичные отчёты).
- «Еда» и «расходники» как NFT (это услуги, а не активы — иначе складывается спекулятивный мусор).
- «Голос» и «внимание» — soulbound, без рынка, иначе рынок захватят скупщики мнений.
- Любые «обещания будущих крольчат» как торгуемые активы (см. 16 про securities: никаких «фьючерсов на выводок», только право на распределение в рамках фактической договорённости).
