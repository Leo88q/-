# 07. Механика разведения: договорённость, процесс, распределение, роялти

## 07.1. Философия: breeding как **расход**, а не как принтер денег

В большинстве GameFi разведение — главный сток, и всё равно проигрывает faucet'у. У нас разведение — дорогое, редкое и ограниченное биологией:

```
Срок одного цикла: 7 (введение) + 3 (сессии) + 31 (беременность) + 14 (неонатальный) + 49 (подсамкой)
                 + 7 (передача) ≈ 111 дней, из них ~100 «животное занято»
Стоимость цикла:   ~1 278 C ($64) + 5–30 B + 30% выводка
  (2 178 C, если стороны выбрали «полный пакет»: фотосессия выводка + премиум-уход)
Лимиты самки:      2 окрола/год, 4 за жизнь, отдых ≥120 дней между окролами
Лимиты самца:      ≤12 сессий/год, ≥14 дней восстановления, потолок 18 крольчат/год суммарно
```

На резиденцию из 240 слотов ≈ 768 животных (из них ≈370 в репродуктивном возрасте; реально доступно ~240 самок × 2 окрола/год минус welfare-«отдых» и моратории по Ne) это **40–60 выводков в год, ~240–380 крольчат в год** при 100% загрузке. Это и есть реальный темп роста популяции — медленнее, чем у P2E, но полностью обеспеченный вольерами.

## 07.2. BreedingBond — ончейн-«договорённость»

```solidity
struct BreedingBond {
  uint256 sireId;              // RCN самца
  uint256 damId;               // RCN самки
  address sireOwner;
  address damOwner;
  Split   split;               // физический сплит (см. 07.5): 50/50, 60/40, 70/30, «royalty-only»
  uint16  royaltySireBps;      // 0..4000 (по умолчанию 4000, из них 2000 — welfare-доля)
  uint16  royaltyDamBps;
  uint32  maxLitters;          // 1..2 (нельзя больше)
  uint32  windowDays;          // 30..365
  uint64  studFeeWei;          // BUNNY, может быть 0
  bool    allowProtocolSale;   // что делать с 30% протокола
  bool    kitRoyaltyMode;      // Mode B (см. 07.4)
  Status  state;               // PROPOSED, ACTIVE, PREGNANT, KINDLED, SETTLED, EXPIRED, CANCELLED
  bytes32 termsHash;           // юридическая привязка офчейн-договора (оферта/лицензия)
}
```

Правила:
- Предложение подписывается обеими сторонами (EIP-712), отозвать можно до начала сессий без штрафа, после — −20% и −50 XP.
- `termsHash` — ссылка на **настоящий** письменный договор (оферта резиденции, правила перевозки, ответственность). Мы не делаем вид, что токен заменяет право владения животным.
- Bond ограничивает: одна самка = активный bond в любой момент времени (только один), чтобы избежать «конвейера».

## 07.3. 12-этапный флоу с welfare-гейтами

| # | Этап | Ончейн-действие | Гейт / условие | Цена |
|---|---|---|---|---|
| 1 | Заявка | `proposeBond()` | оба RCN `ACTIVE`, welfare ≥70, возраст в норме, F рассчитан | 40 C + 3 B (MatchScan) |
| 2 | Сканирование | `matchScan` результат → `CommitmentStore` | расчёт предсказанного диапазона редкости, «health flags» | включено |
| 3 | Подпись | `acceptBond()` | подпись обеих сторон (на Solana — PDA-эскроу вместо EIP-712), депозит 100 C: при окроле **burn**, при пустой вязке **не возвращается** и уходит в фонд содержания (Q16: риск — на игроке) | 100 C + 5 B |
| 4 | Введение 7 дней | `phase=INTRO` | соседние вольеры, визуальный контакт; оператор подтверждает отсутствие агрессии | 90 C |
| 5 | Сессии | `sessionLogged()` ×1–3 | присутствие оператора, закрытый эфир (приватность животных = «закрытые двери», см. 11.9) | 200 C |
| 6 | Подтверждение беременности | `pregnancyAttested()` (12–14 день, пальпация/УЗИ) | 2 подписи оператора + ветеринара; иначе `state=EXPIRED`, возврат 60% взносов | 250 C |
| 7 | Гнездо | `nestBoxFunded()` | краудфанг-цель с авто-возвратом (см. 09.4) | 500 C (сбор) |
| 8 | Окрол | `kindlingRecorded(kitsAlive, kitChipsHash)` | 28–35 дней после сессии; чипы и вес каждого; «мертворождённость» > 50% → авто-расследование | 400 C (care pack) |
| 9 | Ревил генотипов | `revealLitter()` | генотипы посчитаны и опубликованы, родители верифицируемы | 60 C |
| 10 | Подсамкой 49 дней | `lactatingLock` | **жёсткий блок**: продажа/переезд/breeding самки невозможны | — |
| 11 | Отлучка и «социализация» (56 дней) | `weaningCompleted()` | продажа/передача **запрещена до 8 недель** | — |
| 12 | Распределение | `settleLitter()` | emission KitShare, передача protocol-kit, роялти-привязка | 450 C за claim (если есть слот) |

Этапы 4–12 занимают у самки ~100 дней и физически делают разведение «дорогим по времени». Это намеренно: быстрый breeding = плохое содержание.

## 07.4. Распределение выводка: «30% забирают разработчики» — как это устроено честно

Ваш исходный тезис (30% выводка протоколу) оставлен, но реализован в двух режимах, потому что физически «изъять 2 из 5 крольчат» не всегда корректно (например, при выводке из 2 — это потеря 50%, а не 30%; а при 7 — 2.1 округляется до 2 или 3).

**Режим A — «Натуральный» (по умолчанию, для Genesis и мелких выводков):**

```
k           = количество выживших крольчат к 56-му дню
protocolN = ⌊0.30 × k⌋                       (округление вниз)
partiesN  = k − protocolN
split по BreedingBond: 50/50 → sire/partiesN/2, dam/partiesN/2
остаток от округления → сторона, выбравшаяся по hash(litterId) (прозрачно, заранее)
protocol-kit → AdoptionPool: Dutch-аукцион; 100% выручки → Welfare Reserve (кролик остаётся «под патронажем протокола», стримится, имеет право на Legacy)
альтернатива: стороны могут ВЫКУПИТЬ protocol-kit за 110% от цены листинга (деньги — в welfare)
```

**Режим B — «Роялти» (рекомендуется для крупных выводков и «индустриальных» заводчиков):**

```
protocol-kit = 0; стороны забирают всех крольчат физически;
НО на каждого крольчонка навешивается «Lineage Levy»:
  - 30% от роялти с БУДУЩИХ breeding-доходов этой линии (пожизненно, вместо 3% от каждой продажи)
  - первые 4 CareInvoice = 5% super-vat (в welfare), который «гасит» Levy до конца — можно досрочно выкупить за 15 B
```

**Оба режима имеют одинаковую экономику для проекта (~30% ценности), но разный UX.** Выбор фиксируется в Bond и виден второй стороне до подписи.

## 07.5. Варианты сплитов и их экономика

| Сплит | Когда имеет смысл | Бонус/штраф |
|---|---|---|
| 50/50 | Равные партнёры, оба Genesis | стандарт |
| 60/40 или 70/30 | Самец «дороже» ( Legendary/Mythic, высокий CareScore) | цена определяется `MatchScan`: «demand index»; протокол не intervening |
| «Только роялти» (0/0 kit, 100% крольчат самке) | Владелец самки не хочет отдают животных, но платит самцу | stud-fee в BUNNY, 50% burn |
| «Дарственная» | Приют/спасение, вне рынка | 0 комиссий, welfare-XP ×2 |
| «Guild rotation» | Гильдия делит между своими | внутригильейские правила в `WarrenGuild` |

## 07.6. Роялти: двухуровневая модель

```
Уровень 1 — «Родительский роялти» (на продажу RCN потомка):
   5% от цены продажи: 40% владелец отца / 40% владелец матери / 20% Welfare Reserve
   (реализовано через EIP-2981 + RoyaltyEngine; если отец — protocol-kit, его 40% идут в Welfare)

Уровень 2 — «Линейный роялти» (на breeding потомка):
   3 B + 100 C за Bond → 5% этого распределается «долям дома линии» (LineageHouse, 5%)
   и «предкам-чемпионам» (Golden Carrot holder) — 2%
```

Почему на продажу, а не «на каждую игру»: продажа — единственный момент, когда в системе появляется **новая реальная стоимость** от конкретного животного. Роялти, привязанное к абстрактным действиям, деградирует в «налог на активность» и провоцирует обход рынка (private deals). Поэтому:
- Роялти платятся **только при ончейн-передаче с ценой** (рынок/аукцион).
- Для «дарственных» переводов (0 $) — роялти = 0, но `minListingBps` растёт у получателя (чтобы «даром» не обходили).
- Обнуление роялти: через 12 месяцев после смерти последнего из родителей линия «освобождается» (закончилось «право на память»), но 20% welfare-доля **не обнуляется никогда**.

## 07.7. ROFR и защита крольчат

- `ROFR` 30 дней на продажу крольчонка: сначала вторая сторона Bond, затемвладельца `Resident Pass` этого кролика, затем рынок. Цена = заявленная, «перебить» нельзя (при равных условиях выигрывает более ранний заявитель).
- Продажа **до 56 дней** невозможна ончейн. Перевозка до 8 недель — только с ветеринарным разрешением (офчейн-документ, hash в `CommitmentStore`).
- Любой покупатель проходит `EligibilityGate`: верифицированный кошелёк, 18+, юрисдикция без запрета, принятые правила резиденции, подтверждение «я понимаю 12-летнее обязательство» (EIP-712), и — при первом RCN — тест на знание содержания (10 вопросов, 8 правильных). Тест бесплатный, но обязательный. Это снимает половину всех будущих welfare-инцидентов.

## 07.8. Special cases

| Случай | Правило |
|---|---|
| **Genesis × Genesis** | 1 «Genesis-only» помёт, ≥Rare, доп. 200 C fee (в welfare), «Seal» передаётся всем крольчатам |
| Один из родителей в `CARE_REQUIRED` | Bond невозможен |
| Оба CareScore ≥ 90 | Скидка 15% на все этапы, +15 CareBonus, приоритет в очереди персонала |
| Крольчата > числа свободных слотов | Протокол **не минтит** RCN: идёт лист ожидания (публичный `waitlistPosition` в Litter-токене), крольчата остаются на полном содержании резиденции (оплачивается из `CareBondPool` — это и есть назначение оборотного капитала), а «право на слот» торгуется как KitShare+ResidentRight |
| Мёртворождённость/гибель выводка | Возврат 60% всех взносов в CLOVER, 100% — в Endowment самки на восстановление, «Recovery Grant» из Welfare на 3 мес. премиум-содержания, Bond `state=SETTLED` без сплита |
| Развод владельцев (продажа RCN в середине цикла) | Беременная самка не продаётся; если самец продан — роялти переходят новому владельцу, но «lineage» остаётся у предыдущей линии (сигнализируется в метаданных) |
| Смерть родителя после окрола | Крольчата сохраняют Legacy Aura; CareEndowment перераспределяется по 01.7 |

## 07.9. «Этика» как продукт, а не как FAQ

- **Публичный «Breeding Ledger»:** кто, когда, сколько, F-коэффициент каждого выводка, welfare родителей на момент зачатия. Никто не может скрыть, что линия — результат близкородственного спаривания.
- **«Retirement»:** после 4-го выводка самка автоматически получает `RETIREMENT` (пожизненная скидка 40% на CareInvoice, оплачиваемую из «Breeding Welfare Levy») и право на «Sanctuary Crown». Это публичный нарратив: «мы не используем животных до конца».
- **Нейтрализация:** при отказе владельцев от breeding-прав самец/самка проходит вазэктомию/овариогистерэктомию (вет-протокол резиденции), и `neutered=1` в токене. Это не «штраф», а стандарт содержания: парное содержание без размножения — единственная этичная норма для большинства владельцев.
- **Годовой лимит:** «не более 20% популяции резиденции в breeding-цикле одновременно» (иначе facility превращается в завод).
