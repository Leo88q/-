# Landing — Warren Protocol

Статичная витрина продукта: `index.html` + `styles.css` + `app.js`, 20 изображений в `assets/` (10 витринных + 10 запасных фонов/ассетов).
Сборки нет — открывать как есть или через любой статический сервер.

```bash
cd landing && python3 -m http.server 8137 --bind 0.0.0.0
# http://localhost:8137
```

## Визуальный слой (v7 · «кремовая бумага»)

Палитра инвертирована: страница `#F2E9D7`, каждая панель — сплошной `#FFFDF7` (картон/бумага), текст `#141E1A`.
Под текстом картинок нет вообще: `grep` по `styles.css` на `mix-blend` / `mask-image` / `clip-path` / `url(` = 0, 0, 0, 0.

- **Арт — только в рамках.** Две полосы `.art-band` (тропинка после hero, Crown-вольер перед минтом) и три
  иллюстрации `.block-art` внутри блоков: agility-конкурсы (над целями), каталог косметики (в правой колонке донатов),
  студия 01 (в блоке минта). Картинка никогда не лежит под текстом — только в своей рамке с подписью.
- **Мотив игральной карты:** cream-лицо кнопки с чёрным кантом и короткой тенью, пип-масть в углу (♠ / ♥ на действиях),
  чипы-фильтры ♠♥♦, золотая полоска сверху карточек/механик/волн/целей, ♦ вместо буллеттов и после заголовков секций.
- **Окошки-модалки:** сплошная панель с чёрным кантом, **cream-шапка во всю ширину** с золотой «зубчатой» лентой,
  ♦ перед заголовком, 🗝 сверху справа, кнопка-«карта» (поворот 90° при ховере), **рубашка карт тонкой каймой снизу**.
- **Контраст посчитан (WCAG):** основной текст 16.8:1, вторичный 7.4:1, приглушённый 4.6:1, золото 6.1:1,
  крем-кнопка 16.5:1 — всё ≥ 4.5 на обеих поверхностях.
- Кэш-брстер `?v=7` на `styles.css` и `app.js`; правки стилей без него превью может показывать старыми.

Запасные ассеты (`bg-*`, `card-back`, `keyhole-frame`, `pocket-watch`, `mad-hatter-table`, `tarot-void`, `wonderland-bg`)
лежат в `assets/` и **не подключены**: их можно ставить только как отдельные полосы/иллюстрации, не как фон.

## Что работает сейчас (без бэкенда)

| Механика | Реализация |
|---|---|
| Цена кролика 500 $ → SOL | quoting-око 90 с (±1.5 %) поверх живого курса: CoinGecko → Binance → KuCoin → `localStorage`-кэш → встроенный fallback ≈108.50 $ (срез на 2026-10-10) с явной пометкой «приблизительно»; обновление каждые 60 с |
| Кошелёк | детект `window.phantom.solana` / `solflare` / `backpack`, `connect()`, показ адреса; без расширений — модалка с инструкцией |
| Калькулятор месяца заботы | 4 ползунка → ваш вклад в $CLOVER/USD/SOL, % покрытия ядра от опекса $72.50/животн./мес., «хвост» месяца кнопкой доната, Welfare-эффект |
| Реестр 12 карточек | фильтр по редкости, WelfareScore-бар, модалка животного с genotype-лимитками |
| Донат-цели | 4 цели со сметой резиденции, прогресс-бары, quick-donate; «демо-заявка» двигает прогресс и сохраняет в `localStorage` |
| Breeding | дерево предков + распределение редкости (45/30/17/6.5/1.4/0.1 %) |
| Mint | волны, обратный отсчёт до волны 0, вайтлист по email (`localStorage`), счётчик |
| FAQ | 10 вопросов, честные ответы про ончейн-гарантии и «это не инвестиция» |

Ничего не подписывается и не списывается: модалки явно помечают демо-режим (см. `CFG` в `app.js`).

## Что запрещено менять без решения из списка вопросов

- `CFG.RABBIT_USD = 500` + `CFG.WAVES` — цена **волны 1**; волна 0 для вайтлиста 375 $, далее +15 % за волну (⚑ Q5/Q6).
- В цену входит только животное: депозит содержания из кассы убран (⚑ Q5). Газ платит игрок (⚑ Q8).
- `CFG.CLOVER_USD = 0.02` — внутренний референс; в `docs/05` зафиксирован 0.05 $. Расхождение **не решено** (список ниже).
- `CFG.FALLBACK_SOL = 108.50` — только чтобы страница не показывала `—` при недоступных API; в проде количество SOL считает оракул в момент подписания (Q4/Q7), не браузер.
- Доли доната 80/10/10 и роялти 25 % (5/10/5/5) — взято из `docs/06`, `docs/09`.
- Название оператора, адрес резиденции и KYC-гейт **не упоминаются** (решение Q10/Q11): их нет ни в копирайтинге, ни в модалках.
