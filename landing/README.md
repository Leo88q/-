# Landing — Warren Protocol

Статичная витрина продукта: `index.html` + `styles.css` + `app.js`, 10 сгенерированных изображений в `assets/`.
Сборки нет — открывать как есть или через любой статический сервер.

```bash
cd landing && python3 -m http.server 8137 --bind 0.0.0.0
# http://localhost:8137
```

## Что работает сейчас (без бэкенда)

| Механика | Реализация |
|---|---|
| Цена кролика 500 $ → SOL | живой курс: CoinGecko → Binance → KuCoin → `localStorage`-кэш → встроенный fallback ≈108.50 $ (срез на 2026-10-10) с явной пометкой «приблизительно»; обновление каждые 60 с |
| Кошелёк | детект `window.phantom.solana` / `solflare` / `backpack`, `connect()`, показ адреса; без расширений — модалка с инструкцией |
| Калькулятор месяца заботы | 4 ползунка → ваш вклад в $CLOVER/USD/SOL, % покрытия ядра от опекса $72.50/животн./мес., «хвост» месяца кнопкой доната, Welfare-эффект |
| Реестр 12 карточек | фильтр по редкости, WelfareScore-бар, модалка животного с genotype-лимитками |
| Донат-цели | 4 цели со сметой резиденции, прогресс-бары, quick-donate; «демо-заявка» двигает прогресс и сохраняет в `localStorage` |
| Breeding | дерево предков + распределение редкости (45/30/17/6.5/1.4/0.1 %) |
| Mint | волны, обратный отсчёт до волны 0, вайтлист по email (`localStorage`), счётчик |
| FAQ | 10 вопросов, честные ответы про ончейн-гарантии и «это не инвестиция» |

Ничего не подписывается и не списывается: модалки явно помечают демо-режим (см. `CFG` в `app.js`).

## Что запрещено менять без решения из списка вопросов

- `CFG.RABBIT_USD = 500` — entry-цена, задана владельцем продукта.
- `CFG.CLOVER_USD = 0.02` — внутренний референс; в `docs/05` зафиксирован 0.05 $. Расхождение = открытый вопрос Q1.
- `CFG.FALLBACK_SOL = 108.50` — только чтобы страница не показывала `—` при недоступных API; в проде количество SOL считает оракул в момент подписания (Q4/Q7), не браузер.
- Доли доната 80/10/10 и роялти 25 % (5/10/5/5) —taken из `docs/06`, `docs/09`.
